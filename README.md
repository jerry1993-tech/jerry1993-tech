## About

I'm an **AI Full-Stack Engineer** working across the LLM stack: post-training, agents, retrieval, and the engineering that puts them into production. I build in the open and care about systems that hold up outside the demo.

- **Building** [Cornucopia](https://github.com/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese) — an open-source Chinese financial LLM series and a lightweight vertical-domain training stack (pretraining → SFT → RLHF → quantization).
- **Exploring** agentic RL with GRPO, multi-turn tool use, sandboxed execution, and execution-verified rewards.
- **Designing** production-grade multi-agent architectures, collaboration patterns, and workflow engines.
- **Based in Norway** · open to collaboration and AI engineering opportunities.

## Focus

| Area | Work |

## Selected Work

### Flagship

- [**Cornucopia-LLaMA-Fin-Chinese**](https://github.com/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese) <a href="https://github.com/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese/stargazers"><img alt="Cornucopia-LLaMA-Fin-Chinese stars" src="https://img.shields.io/github/stars/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese?style=flat-square&label=stars&color=A9791E&labelColor=0B1220"></a> <a href="https://github.com/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese/network/members"><img alt="Cornucopia-LLaMA-Fin-Chinese forks" src="https://img.shields.io/github/forks/jerry1993-tech/Cornucopia-LLaMA-Fin-Chinese?style=flat-square&label=forks&color=2A7F75&labelColor=0B1220"></a> — An open-source Chinese financial LLM series with a lightweight vertical-domain training framework covering pretraining, SFT, RLHF, and quantization.

### Agent Systems

- [**Cornucopia-Multi-Agent**](https://github.com/jerry1993-tech/Cornucopia-Multi-Agent) <a href="https://github.com/jerry1993-tech/Cornucopia-Multi-Agent/stargazers"><img alt="Cornucopia-Multi-Agent stars" src="https://img.shields.io/github/stars/jerry1993-tech/Cornucopia-Multi-Agent?style=flat-square&label=stars&color=A9791E&labelColor=0B1220"></a> — Production-grade multi-agent orchestration: 6 collaboration modes, 8 specialized tools, and 4 execution paths, built with FastAPI and Streamlit.
- [**mimo-agent-grpo-swift**](https://github.com/jerry1993-tech/mimo-agent-grpo-swift) <a href="https://github.com/jerry1993-tech/mimo-agent-grpo-swift/stargazers"><img alt="mimo-agent-grpo-swift stars" src="https://img.shields.io/github/stars/jerry1993-tech/mimo-agent-grpo-swift?style=flat-square&label=stars&color=A9791E&labelColor=0B1220"></a> — End-to-end reproduction of MiMo-V2.6's interactive Agent RL pipeline on MS-Swift: multi-turn tool use, sandboxed execution, real-execution verification, and GRPO.
- [**aligo-travel-agents**](https://github.com/jerry1993-tech/aligo-travel-agents) <a href="https://github.com/jerry1993-tech/aligo-travel-agents/stargazers"><img alt="aligo-travel-agents stars" src="https://img.shields.io/github/stars/jerry1993-tech/aligo-travel-agents?style=flat-square&label=stars&color=A9791E&labelColor=0B1220"></a> — Enterprise-grade multi-agent travel assistant built from scratch on AgentScope 2.0.
